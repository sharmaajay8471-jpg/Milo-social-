# Milo Social — Firebase-ready MVP

Includes Flutter UI and service architecture for:
- Login/register
- Home feed
- Posts
- Search
- Profile
- Chat
- Firestore data service
- Firebase Auth service
- Firebase Storage/Firestore security-rule templates
- Play Store checklist

The package is not connected to a real Firebase project yet because that requires your own Firebase project credentials. Calling also needs an RTC provider/backend.
